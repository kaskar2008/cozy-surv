# 🏝️ Уютный остров

Браузерная игра про обустройство собственного шелтера — снаружи и внутри. Мир — настоящее 3D (Three.js) с изометрической камерой, которую можно поворачивать.
**Без зомби, без паники, без смерти.** Только костёр, чайник, огород, дождь за окном и всё время мира.

Мир и звук — процедурные (модели собираются кодом из низкополигональных примитивов). Значки интерфейса — эмодзи, которые на лету заменяются картинками Twemoji (`js/core/emoji.js`), чтобы выглядеть одинаково на любой платформе. Единственная зависимость — Three.js.

## Запуск и сборка

```bash
npm install
npm run dev        # разработка: http://localhost:5173 (Vite, горячая перезагрузка)
npm run build      # продакшн-сборка в dist/
npm run preview    # посмотреть собранную версию
```

Игра сама сохраняется (каждые 30 секунд и при закрытии вкладки). При создании игры можно выбрать, где хранить:
**на устройстве** (`localStorage`, без регистрации) или **в облаке** (аккаунт по почте и паролю, Firebase Auth + Firestore, играть можно с любого устройства).
При заходе открывается **главный экран** (продолжить, новая игра, настройки, как играть) с фоном-параллаксом: каждый раз случайный мир и время суток. Вернуться на него можно из игры: ⚙️ → «В главное меню».
`?fresh=1` в адресе — сразу начать заново, минуя главный экран. Своего сервера нет: `dist/` — это обычная статика, облаком служит Firebase.
(Без Node можно и так: `python3 serve.py` — простой сервер для исходников без сборки.)

## Деплой (Firebase Hosting — бесплатный хостинг Google)

Автоматически: каждый push в `main` собирает проект и выкладывает `dist/` через GitHub Actions (`.github/workflows/deploy.yml`).

Один раз настроить:
1. Создать проект на https://console.firebase.google.com и включить **Hosting** (тариф Spark — бесплатный).
2. Выпустить ключ сервисного аккаунта и сохранить в GitHub Secret. Проще всего командой (в корне проекта, после `npx firebase-tools login`):
   `npx firebase-tools init hosting:github` — она сама создаст сервисный аккаунт и секрет `FIREBASE_SERVICE_ACCOUNT` в репозитории
   (на вопросах про сборку и workflow: public directory `dist`, SPA — нет, свой workflow не перезаписывать).
3. В репозитории GitHub: Settings → Secrets and variables → Actions → **Variables** → добавить `FIREBASE_PROJECT_ID` = id проекта Firebase.
4. Прописать id проекта в `.firebaserc` (`{"projects":{"default":"<id>"}}`).

Вручную: `npx firebase-tools login && npm run deploy`.

## Облачное сохранение (один раз настроить)

Пока `apiKey` в `js/config/firebase.js` пустой, кнопка «В облаке» в игре недоступна (локальное хранение работает всегда).

1. В консоли Firebase → **Authentication** → Sign-in method → включить **Email/Password**.
2. **Firestore Database** → создать базу (режим production, любой регион).
3. Зарегистрировать веб-приложение: `firebase apps:create web cozy-island`, затем `firebase apps:sdkconfig web` и перенести `apiKey` и `appId` в `js/config/firebase.js`.
4. Опубликовать правила доступа (каждый видит только своё сохранение): `firebase deploy --only firestore:rules`.
5. Если игра открывается на своём домене — добавить его в Authentication → Settings → Authorized domains.

Сохранение — один документ `users/{uid}/saves/main` (сжато gzip). Облако обновляется раз в минуту и при сворачивании вкладки; если игру с другого устройства сохранили позже, игра предложит выбрать, какую оставить.

## Управление

| Действие | Как |
|---|---|
| Идти / собрать ресурс / выбрать постройку | ЛКМ |
| Камера | ПКМ + перетаскивание, прокрутка двумя пальцами на тачпаде, `WASD`/стрелки, колесо или щипок — масштаб, `Q`/`E` (или ⟲ ⟳ сверху) — повернуть на 90°, `Пробел` — к персонажу |
| Войти в дом | двойной клик по дому (или кнопка в панели) |
| Строить | выбрать карточку внизу → ЛКМ. `R` — повернуть, после постройки режим выключается сам (`Shift` — ставить подряд), ПКМ/`Esc` — отмена, тянуть мышью — ставить дорожки, заборы, трубы |
| Снести (вернёт 60%) | `X` или кнопка «Снести» |
| Рюкзак / Крафт / Журнал | `I` / `C` / `J` |
| Скорость времени | `P` пауза, `1` ×1, `2` ×2, `3` ×4 |
| Фото острова | `F` или 📷 |
| Скрыть/показать панель строительства | `B` |

## Что внутри

**91 постройка снаружи + 48 предметов мебели внутри**, 82 предмета, 54 рецепта, 39 «мягких» целей,
27 комбинаций-«синергий», 10 культур, 4 сезона, погода, день/ночь.

### Строительство «как в RTS»
Выбрал постройку → призрак на сетке (зелёный/красный) → клик → постройка появляется **сразу готовой**
(с лёгкой анимацией). Цветные пунктирные линии на призраке показывают, **с чем она соединится**.
Часть построек открывается по цепочке: нужно один раз построить предыдущую (замочек в карточке подскажет).

### Постройки дружат друг с другом (вплотную!)
- **Вода:** дождесборник (фильтр: песок + уголь) копит всего 8 единиц → поставь вплотную **бак** (40) или **цистерну** (160), протяни **трубы** (тянутся мышью) → к сети подключаются дождеватели, душ, купель, фонтан, поилки, грядки, баня, дом. Колодец даёт воду вечно, но медленно. **Насос** у озера качает воду, если рядом есть ток.
- **Электричество:** солнечная панель (зависит от солнца и погоды) → провода → аккумулятор → фонари, гирлянды (соседние гирлянды сами соединяются и передают ток), радио, насос; к дому подключается изнутри (торшер, холодильник, проигрыватель).
- **Огонь и тепло:** котелок и чайник работают **только вплотную к горящему огню**; купель греется от соседнего костра; сушилка рядом с огнём сушит вдвое быстрее; **дровница** рядом с костром, баней или печью сама подкладывает дрова из запасов.
- **Автоматизация:** **ящик/корзина вплотную** к курятнику, улью, ловушке — сам забирает продукцию. **Кормушка** и **поилка** (подключённая к воде) вплотную к курятнику/загону кормят и поят сами.
- **Огород:** компост в 3 клетках от грядки удобряет при посадке; пугало ускоряет рост; пчёлы рядом = лишний урожай и мёд быстрее от цветов; труба вплотную или дождеватель поливают сами; **теплица** растит зимой.
- **Дом:** хижине/дому можно пристроить **дымоход** — без него внутри нельзя поставить камин, печку и плиту. Из трубы идёт дымок, когда внутри топится; по вечерам светятся окна.

### Дом изнутри
Палатка → хижина → дом (улучшение «на месте», мебель сохраняется). Внутри — вид «в разрезе»:
48 предметов (кровати, кресла, диван, камин, плита, раковина, ванна, пианино, гитара, мольберт, аквариум, картины, шторы, окна со «своим небом», часы, гирлянды…),
ковры можно класть под мебель, на стены вешать картины (их ты рисуешь сам на мольберте), можно менять цвет стен и пола, переодеваться в шкафу.
Раковина/ванна работают, если к дому подведена вода; торшер/холодильник/проигрыватель — если подключён ток.

### Уют и синергии
Мебель и украшения дают «уют» (счётчик слева), а ещё есть **27 комбинаций** («Посиделки у костра», «Спальный уголок»,
«У камина», «Читальный уголок», «Пчелиный луг», «Огород мечты», «Звёздная площадка» …) — их условия видны в Журнале (вкладка «Уют»).
Уют поднимает настроение, питомцы и путники приходят к уютным местам.

### Жизнь на острове
- **Потребности без наказаний:** жажда, сытость, бодрость, тепло, настроение. Ничто не убивает — просто с ними приятнее (мягкие подсказки).
- **Время:** сутки = 5 минут, сезон = 6 суток; весна, лето, осень, зима (зимой на улице ничего не растёт). Ускорение ×1/×2/×4, сон автоматически ускоряет ночь.
- **Погода:** ясно, облака, дождь, туман, снег; радуга после дождя, северное сияние зимой, падающие звёзды, светлячки, бабочки, птицы, осенние листья.
- **Сбор:** ягоды, грибы, травы, цветы, тростник, глина, песок, хворост, камни, валуны, ржавые обломки, ракушки; деревья спиливаются и **вырастают заново** (саженцы можно сажать самому).
- **Готовка:** костёр, котелок, чайник, хлебная печь, уличная кухня/плита, коптильня, бродильня, сушилка, жернова, ветряная мельница — **~30 блюд** (супы, чаи, хлеб, пироги, пицца, торт, омлет, блины, варенье, сыр, квашеная капуста…).
- **Живность:** куры, коза, пчёлы, рыба (удочка, причал, ловушка), кот или пёс (домик → через время кто-то поселяется; гладить кликом).
- **Досуг:** посидеть (пенёк, скамья, качели, пикник, столик под зонтом), гамак, телескоп (ночью — звёздное небо), граммофон, баня и купель, душ, чтение, музыка, рисование, дневник.
- **Гости и письма:** вечером к огню иногда приходит **путник** (история и подарок), в **почтовый ящик** приходят письма с подарками.
- **Цели:** журнал из 39 мягких «чем бы заняться» — за каждую небольшой подарок. Никакой спешки.

## Структура проекта

```
index.html, css/style.css        — страница и стили
serve.py                          — dev-сервер без кэша
js/main.js                        — запуск и главный цикл
js/core/                          — util, iso (3D-«кисть»: примитивы box/cyl/blob/gable… пишут треугольники), audio (процедурный звук)
js/data/                          — предметы, культуры, рецепты, ресурсные узлы, мебель
js/data/buildings/*.js            — каталог построек (данные + рисование каждой)
js/game/                          — состояние, мир, инвентарь, сети, симуляция, API действий, интерьеры, уют, цели, события, сохранение
js/render/                        — камера (ортографическая, поворот 90°), gl (Three.js), models (кэш 3D-моделей и инстансинг), земля, сцена, стройка, персонажи; 2D-оверлей: освещение, погода, частицы, значки
js/ui/                            — HUD, панель строительства, панель объекта, окна, главный экран (mainMenu.js) и его параллакс-фон (menuBg.js)
js/input.js                       — мышь/клавиатура, призрак постройки, выбор объектов
```

### Как добавить постройку
Описание — обычный объект в `js/data/buildings/*.js` (`reg([...])`): `id, name, cat, icon, size, cost, req, desc` и функция `draw(c, b, o)`,
которая собирает постройку из 3D-примитивов `core/iso.js` (`box`, `cyl`, `gable`, `blob`, `line3`, `plane` — плашка-текстура на земле…): координаты в клетках, высоты в «пикселях» (≈ 1/39 клетки). Модель строится один раз и дальше рисуется инстансингом; движущиеся детали — в `anim(c, b, t, o)` (перестраиваются каждый кадр). Поведение включается декларативно:
`burner` (топливо), `station` (рецепты), `net` (вода/ток), `out` (производство), `sit`, `light`, `needs: ['heat']` и т.д.
Отдельную логику можно добавить в таблицу `UPD` в `js/game/sim.js`.
